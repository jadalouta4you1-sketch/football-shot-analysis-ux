# Prototype and first walkthrough

[Try the working prototype](https://jadalouta4you1-sketch.github.io/football-shot-analysis-ux/) · [Open the Figma prototype](https://www.figma.com/proto/UZGFEctx8ckCYBNd13DlqQ/JAD-ALOUTA---UX-UI-Semester-Project---Figma-Design--HW06-10-?node-id=2-161&starting-point-node-id=2%3A161)

**Walkthrough task.** Tomorrow’s debrief starts with one video sequence. Choose a match, pick the zone you want to discuss, and save your choice. Explain how you know which zone was saved.

| Scripted first-trial observation | Interpretation | Design response |
|---|---|---|
| P1 picked 50% before reading the two attempts. | A correct choice can still have a weak explanation. | Keep attempts and goals beside the rate. |
| P2 asked which pitch markers represented goals. | Position alone does not explain outcome. | Put the marker key beside the pitch. |
| P3 returned to the comparison to check what was saved. | The review screen could be mistaken for the receipt. | Repeat the match and zone after saving. |

The original design walkthrough also identified missing save feedback. The revised browser flow reaches a receipt with the match, zone and note. It includes fixtures with missing data, tied rates and zero attempts. The data are illustrative and saves last for the demo session.
