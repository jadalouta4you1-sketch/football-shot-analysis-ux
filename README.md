# Football Shot Analysis for Training Decisions

A single UX/UI semester project exploring whether a shot map alongside match statistics helps a football coach compare zones and choose a candidate pattern for video review. The project is developed through the course stages; these are not ten separate projects.

**Current status:** The problem frame and design direction are documented. Match values are illustrative. Participant research and comparative usability testing are still pending, so no improvement in accuracy or speed is claimed.
