## FigJam artifacts to include

Organize the board so a reviewer can find these connected pieces in order:

1. **Starting point:** problem, target user/situation, user goal, organization goal, constraints, assumptions, proposed success criterion.
2. **Research:** research question, method choice, participant criteria, anonymized observations, affinity clusters, evidence-based insights, persona and journey if the evidence supports them.
3. **Kickoff:** brief, stakeholders, target user/need/user story, problem statement, HMW prompts, prioritization matrix with stated criteria.
4. **Information architecture:** content inventory/labels, sitemap, main flow and edge branches.
5. **Testing and iteration:** test tasks, consent/ethics note, measured observations, severity-ranked findings, decision log, next steps.

Do not fill research outputs, matrix scores, participant quotes, or usability results with guesses. Label unknowns as assumptions or pending work.
